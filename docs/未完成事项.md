## 6. 更新规则

1. 开始任务时将状态改为 `进行中`，并写明实际负责人。
2. 外部环境、凭据或测试结果未就绪时使用 `等待外部条件`，不得标记完成。
3. 完成任务时补充验证命令、测试结果、关联提交或验收记录链接。
4. 联调发现的新问题先写入《开发问题记录》，确认阻塞 Phase 1 后再追加到本清单。
5. Phase 1 只有在 P1-01 至 P1-05 全部完成并经开发者确认后才能关闭。
6. Phase 2 每个分块完成后先评审和提交，再进入下一块。
