## 1. 验收范围

本记录覆盖 M2.1 好友与在线状态最小闭环：

- 好友关系迁移、状态机、并发幂等、软删除与重新申请。
- 用户搜索、好友申请/接受/拒绝、好友列表/删除 REST 与 OpenAPI。
- Redis connection ID presence 租约、Lua CAS、IM 生命周期观察。
- `presence` 与 `friendship_updated` 服务端事件。
- Vue `/friends` 页面、类型化 API、好友 Store 与全局 IM Store。
- 自动连接、Token 临期刷新、一次握手刷新、指数退避、4001 终止重连和登出清理。

不包含 M2.2 聊天、M2.3 群组、M2.4 多人房间、跨实例广播或完整离线同步。
