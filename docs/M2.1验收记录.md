## 5. 本地双账号真实浏览器补充验收

### 5.1 临时环境

- 临时 MySQL 8.4、Redis 7、MinIO；空测试库执行 001—017 迁移。
- Go API：`http://127.0.0.1:18081`。
- 两套独立 Vue Origin：`http://127.0.0.1:15174`、`http://127.0.0.1:15175`。
- 本地验收账号：`m21alice921`、`m21bob921`；数据只用于本次临时环境。

### 5.2 步骤与结果

| 场景 | 结果 |
|---|---|
| 搜索 | 用户名、用户 ID 与昵称三种查询均返回目标账号；邮箱不参与搜索 |
| 申请与拒绝 | Alice 发起申请，Bob 实时收到；Bob 拒绝后双方待处理列表实时清空；重新查询后可再次申请 |
| 接受与刷新恢复 | Bob 接受后双方好友列表实时出现且显示在线；双方刷新页面后由 REST 恢复一致的 accepted 关系 |
| 删除与重加 | 通过精确 DELETE REST 删除临时好友关系，双方页面实时移除；随后浏览器重新申请并接受，双方列表恢复一致 |
| 在线/离线 | 关闭 Bob 浏览器页后 Alice 实时显示离线；重新打开 Bob 独立 Origin 后 Alice 实时恢复在线 |
| 4001 接管 | Alice 打开第二页面后，旧页面显示连接被新页面接管且不再自动重连；新页面保持实时连接正常 |
| Redis 故障降级 | 停止临时 Redis 后手动刷新好友数据，Bob 状态显示“状态未知”，没有误报为离线 |
