### DEV-001：PostCSS 路径遍历漏洞

- **发现日期**：2026-07-29
- **状态**：待确认
- **严重程度**：高
- **影响范围**：Vue 前端构建依赖
- **发现方式**：`npm audit --omit=dev`
- **现象**：当前依赖树包含 `postcss <= 8.5.17`，命中 `GHSA-r28c-9q8g-f849`。
- **当前影响**：不阻塞 TypeScript 检查和生产构建，但在处理不可信 Source Map 时可能造成 `.map` 文件泄露。
- **建议处理**：单独执行受控依赖升级，检查 `package-lock.json` 变更后重新运行 `npm audit` 和 `npm run build`。

### DEV-002：前端主包体积超过 Vite 默认阈值

- **发现日期**：2026-07-29
- **状态**：待确认
- **严重程度**：中
- **影响范围**：Vue 前端首屏加载
- **发现方式**：`npm run build`
- **现象**：主 JavaScript Chunk 约 1.19 MB，超过 Vite 默认的 500 KB 提示阈值。
- **当前影响**：不阻塞 MVP 构建，可能增加首屏下载和解析时间。
- **建议处理**：在功能页面稳定后检查 Element Plus 引入方式，并按路由或组件进行代码分割。

### DEV-003：VueUse PURE 注解构建警告

- **发现日期**：2026-07-29
- **状态**：待确认
- **严重程度**：低
- **影响范围**：第三方依赖构建优化
- **发现方式**：`npm run build`
- **现象**：Rolldown 无法识别 `@vueuse/core` 部分 `/* #__PURE__ */` 注解的位置，并忽略对应注解。
- **当前影响**：不影响构建成功或运行正确性，可能轻微影响 Tree Shaking。
- **建议处理**：跟随 Vite、Element Plus 或 VueUse 后续兼容版本升级，不直接修改 `node_modules`。

### DEV-004：Python 接口测试偶发 AnyIO 资源警告

- **发现日期**：2026-08-03
- **状态**：待确认
- **严重程度**：低
- **影响范围**：Python FastAPI 接口测试
- **发现方式**：`python -m unittest discover -s tests -v`
- **现象**：部分 `TestClient` 用例结束后偶发 `ResourceWarning`，提示 AnyIO 内存流未关闭；截至 M1.4 暂停时，103 项测试仍全部通过。
- **当前影响**：未发现功能错误或测试泄漏导致的失败，但会增加测试日志噪声，长期运行时需要确认资源是否完整释放。
- **建议处理**：单独检查 FastAPI、Starlette、HTTPX 与 AnyIO 版本组合及测试生命周期，必要时增加资源警告严格模式后修复。

### DEV-005：pymilvus 2.4.15 仍依赖已弃用的 pkg_resources

- **发现日期**：2026-08-03
- **状态**：待确认
- **严重程度**：低
- **影响范围**：Python Milvus 客户端初始化
- **发现方式**：导入 `pymilvus.Collection` 并核对本地调用签名
- **现象**：`pymilvus` 导入时提示 `pkg_resources` API 已弃用；当前锁定的 Setuptools 80.9.0 下仍可正常导入。
- **当前影响**：不影响现有检索代码和测试，但未来升级 Setuptools 后可能出现导入兼容问题。
- **建议处理**：后续优先评估升级兼容的 pymilvus 版本；在完成 Milvus 集成回归前，不单独升级或解除 Setuptools 版本锁定。
