## 1. 已完成范围

- Go：PDF 上传校验、MinIO 存储、分页列表、详情、删除和用户归属校验。
- Go：Python 解析任务调用、内部状态回写、共享密钥鉴权及 `chunk_count` 持久化。
- Go：失败剧本重新解析接口、用户归属校验及原子状态切换。
- Python：MinIO 临时下载、逐页 PDF 提取、文本清洗、章节切片和页码元数据。
- Python：BGE 1024 维向量生成、Milvus Collection、批量写入和重复解析幂等清理。
- Python：后台解析编排、成功/失败回调和临时文件异常路径清理。
- 删除闭环：Milvus 向量、MinIO 对象和 MySQL 记录依次清理。
- Vue：剧本列表、分页、状态轮询、PDF 上传、详情、错误展示和删除确认。
- Vue：失败剧本重新解析入口及重复提交保护。
- Vue：Vitest 自动化覆盖 PDF 上传校验、解析状态轮询终止、错误及重试入口展示。
