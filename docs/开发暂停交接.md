## 3. 当前接口与状态边界

- `POST /api/v1/ai/inference/start`
  - Go 内部调用，要求 `X-Internal-Secret`；
  - RAG 检索剧本开场片段，组装上下文并返回完整开场叙事。
- `POST /api/v1/ai/inference/action`
  - Go 内部调用，要求 `X-Internal-Secret`；
  - 从 Redis 只读加载 `room:{room_id}:summary`、`room:{room_id}:rounds`、`room:{room_id}:player:{user_id}`；
  - 调用 GLM Function Tool，骰子结果由 Python 服务端立即执行；
  - 其余状态调用经过白名单、参数及目标玩家校验后，以 `status_changes.calls` 返回。

M1.4 推理层不会直接写入角色状态。M1.5 游戏状态层需要负责校验 `status_changes`，并在统一的事务、幂等和权限边界内写入 Redis/MySQL，避免形成两条状态变更路径。
