## 3. 恢复开发时的顺序

1. 确认仍位于 `dev/feature`，执行 `git status --short`，不得覆盖或丢弃现有未提交变更。
2. 执行 `.\scripts\verify-m13.ps1`，确认非 Docker 验证仍然通过。
3. 在具备 Docker CLI 的环境执行 `.\scripts\verify-m13.ps1 -RequireDocker`。
4. 在全新 MySQL 实例验证 `001` 至 `004` 迁移。
5. 运行 `generate-m13-fixtures.py --verify` 生成正常文本、重复页眉页脚、扫描型/空白三类 PDF，并完成端到端验收。
6. 验证重复解析和删除后的 MySQL、MinIO、Milvus 一致性。
7. 更新 M1.3 验收记录并提交当前变更。
8. M1.3 正式验收完成后，再制定并启动 M1.4 开发。
